# Fontify | مكتبة الخطوط الذكية

Fontify is a Flutter application for discovering, previewing, comparing, and saving Arabic and Latin typefaces.

## Current implementation

- Material 3 interface with light/dark themes.
- Arabic/English interface direction and language toggle.
- Curated Google Fonts catalogue with source and license metadata.
- Search and filters by script, category, and style.
- Interactive preview lab: sample text, size, weight, foreground/background colors.
- Side-by-side comparison of up to three typefaces using identical text.
- Persistent favorites and preferences using SharedPreferences.
- Font detail pages with specimen text, metadata, supported scripts, and official source links.

## Requirements

- Flutter stable (Dart SDK compatible with the constraint in `pubspec.yaml`)
- Android Studio / Android SDK for Android builds

## Run

```bash
flutter pub get
flutter run
```

## Verify

```bash
flutter analyze
flutter test
```

## Architecture

Feature-oriented layered structure:

- `core/`: theme, localization, shared utilities and constants
- `data/`: font catalogue, models, repositories and local persistence
- `providers/`: app state and user preferences
- `screens/`: app pages
- `widgets/`: reusable UI components

## Font data and licensing

The bundled catalogue is a curated metadata list for Google Fonts families. Font previews are rendered by the `google_fonts` package; first-time preview may require an internet connection. The source links lead to the official Google Fonts specimen pages. The catalogue labels the listed families as SIL Open Font License (OFL); always review the individual family license and its current terms before redistribution or commercial embedding.

Fontify does not bundle font binaries or claim ownership of third-party typefaces.
