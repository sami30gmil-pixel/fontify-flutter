# Fontify | مكتبة الخطوط الذكية

تطبيق Flutter لاستكشاف الخطوط العربية واللاتينية ومعاينتها ومقارنتها وحفظ المفضلة.

## الميزات الحالية
- واجهة Material 3 مع الوضعين الفاتح والداكن.
- تبديل العربية والإنجليزية واتجاه RTL/LTR.
- كتالوج منسق لعائلات خطوط Google Fonts مع بيانات التصنيف واللغات والأوزان والاستخدامات.
- بحث وتصفية حسب التصنيف واللغة.
- مختبر معاينة للنص مع تغيير الخط والحجم والوزن والألوان.
- مقارنة حتى ثلاثة خطوط بالنص نفسه.
- تفاصيل الخط وروابط المصدر الرسمي ومعلومات الترخيص.
- مفضلة وإعدادات محفوظة محلياً عبر SharedPreferences.

## التشغيل
يتطلب Flutter stable وAndroid SDK.

```bash
flutter pub get
flutter run
```

## الفحص
```bash
flutter analyze
flutter test
```

## البنية
- `lib/core`: الثيم والأدوات المشتركة.
- `lib/data`: نماذج البيانات ومستودع الخطوط.
- `lib/providers`: إدارة الحالة والتفضيلات.
- `lib/screens`: الشاشات.
- `lib/widgets`: المكونات المشتركة.

## بيانات الخطوط والترخيص
الكتالوج الحالي قائمة بيانات منتقاة لعائلات منشورة على Google Fonts، وتُحمّل المعاينات عبر حزمة `google_fonts` وقد يتطلب أول تحميل اتصالاً بالإنترنت. روابط المصدر تقود إلى صفحات Google Fonts الرسمية. لا تتضمن النسخة ملفات خطوط مضمّنة أو مستضافة محلياً؛ تحقق دائماً من ملف الترخيص الخاص بكل عائلة وشروطه الحالية قبل إعادة التوزيع أو الاستخدام التجاري.

## حالة المنصة
تم رفع مصدر Flutter وملفات الإعداد والاختبار. لم يتم توليد مجلدات المنصات الأصلية (مثل `android/`) في بيئة هذه الجلسة؛ ولإنشاء مشغل Android القياسي نفّذ `flutter create . --platforms=android` من جذر المشروع باستخدام Flutter SDK قبل البناء.
